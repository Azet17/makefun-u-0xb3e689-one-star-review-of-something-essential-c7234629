## What it writes

Running `node main.ts` writes exactly one line to `/output/entry.txt`:

> Gravity: holds everything together every single day, then drops your phone face-down the one time its screen is already cracked.

## Why this line

Gravity is an everyday essential no one can opt out of, and the review is unmistakably about the thing itself — it holds everything together, relentlessly, every single day. The grievance is the sharpest true one: things do not just fall, they fall face-down at the worst possible moment, when the screen is already cracked. The tone stays deadpan from start to finish — one star, no winking, no exclamation marks — and the sting ("already cracked") arrives only in the last few words, after the complaint has been read straight. One joke, told cleanly, with nothing extra crowding it.

## Run

```sh
node main.ts
```

No dependencies. The program creates `/output` if needed and writes `/output/entry.txt` with no trailing newline.
